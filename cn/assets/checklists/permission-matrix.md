# Permission Matrix 模板

用于把工具、数据、动作和人工确认要求写成可审计的权限边界。默认拒绝未列出的资源和动作；高风险写入、外发、审批或发布必须经过人工确认。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `主体` | Agent、角色或服务身份。 |
| `工具 / 资源` | 工具名称及其访问对象。 |
| `操作` | `read`、`write`、`execute`、`send` 等最小动作。 |
| `数据范围` | 租户、目录、字段或数据分类限制。 |
| `允许条件` | 时间、环境、参数校验等前置条件。 |
| `人工确认` | `否`、`是`，或描述必须确认的门禁。 |
| `审计要求` | 必须记录的 Trace、Artifact、审批人和结果。 |
| `拒绝 / 升级` | 不满足条件时的拒绝码和升级路径。 |

## 最小示例

| 主体 | 工具 / 资源 | 操作 | 数据范围 | 允许条件 | 人工确认 | 审计要求 | 拒绝 / 升级 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `code-repair-agent` | `repo` | `read` | 当前仓库 | 只读工作区 | 否 | `trace_id`、路径 | 越界则 `permission_denied` |
| `code-repair-agent` | `test-runner` | `execute` | 固定测试命令 | 沙箱、无网络 | 否 | 命令、退出码、耗时 | 失败可重试 2 次 |
| `code-repair-agent` | `repo` | `write` | 生产代码目录 | 补丁通过 Validator | 是 | 补丁 hash、确认人 | 转人工审批 |
| `procurement-agent` | `采购系统` | `submit` | 当前采购单 | 金额和供应商已校验 | 是 | 审批记录、Artifact | 拒绝提交并通知负责人 |

未列出的工具、资源和动作：拒绝执行，并记录 `permission_denied`。

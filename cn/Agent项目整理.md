- 去重规则：同一 GitHub 仓库视为同一项目；没有仓库时按项目/论文标题归并。

## 后续使用建议

- 如果目标是快速入门，先读“综述与资源合集”和“基础理论与经典方法”。
- 如果目标是做工程实现，优先从“核心框架与多智能体系统”“工具使用、GUI 与代码自动化”中选项目跑通。
- 如果目标是写论文选题，优先看“记忆、规划与长期任务”“Agent+RL 与训练优化”“顶会论文”相关条目。
- 如果目标是落地行业应用，优先筛选带 GitHub 仓库、带 Benchmark、带真实任务场景的项目。
- 对只有标题和 arXiv 链接的条目，建议后续补充摘要、任务定义、数据集、指标和是否开源。

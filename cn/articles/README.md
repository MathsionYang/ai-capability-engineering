# AI 能力工程文章目录

本目录只存放中文知识文章原稿，所有文章直接放在 `articles/` 根目录，不再按层级建立子文件夹。文章的层级归属、阅读顺序和阶段交付状态统一在本文维护；模板、案例、评估数据和报告放在同级的 `assets/` 目录。

## 目录边界

```text
cn/
  index.md                    总入口
  articles/                   全部知识文章（扁平存放）
    README.md                 文章归属与交付状态说明
  assets/                     模板、案例、图表和评估数据
  路线/                       路线、写作计划、Checklist 和发布资料
  生产治理层说明.md           生产治理层的占位说明
```

文章文件名保持原有标题，避免历史引用失效。文件名中的主题词不是层级判断依据，层级以本文的归属表为准。

## 文章类型标记

文章目录中的文章按用途分为三类：

- `基础文章`：建立概念、原则和设计方法，通常是某条阅读链路的上游。
- `专题文章`：深入一个工程问题，提供实现细节、失败模式和检查项。
- `整合文章`：把多个专题、统一案例和资产串成一个可运行的阶段交付物。

当前唯一的整合文章是阶段 1的《Agent 可信执行闭环：从 Trace、Evals 到可恢复执行》。它引用的 Schema、Checklist、案例和评估数据均位于 `assets/`，不在文章目录中重复维护副本。

## 推荐阅读顺序

总纲 -> 基础层 -> 执行层 -> 可靠性层 -> 协作层 -> 安全层 -> 生产治理层。

可靠性层内部先读《Agent 可观测性实战：从日志、Trace 到 Replay》，再读 Tracing 专题；完成五篇可靠性专题后，再读可信执行闭环整合文章。进入阶段 2前，补读协作层和安全层；进入阶段 3前，回看权限矩阵、评估门禁和案例运行记录。
